# Кейс AR-09: прогноз длины ответа LLM

Оформляется по `cases/template` арены и копируется в `cases/ar09` её репозитория.

## Задача
- Вход: батч строк `{"rows": [{"id", "prompt", "model", "input_tokens"}, ...]}` — запрос, имя модели (одна из 13 open-source моделей CASTILLO) и длина запроса в её токенах.
- Ответ: `{"<id>": {"pred", "lo", "hi"}, ...}` — точечный прогноз числа выходных токенов и интервал 10 %–90 % для каждой строки.
- Разрешённые материалы: train (`case/dataset/data/castillo.train.jsonl`) целиком, включая `meta`; пакеты образа runner. Сеть, public и private недоступны.

Подробные условия и формулы — в [campaign/campaign.md](campaign/campaign.md).

## Разрешённые изменения
Что исследователь может менять: код решателя, признаки, статистики и веса, обученные на train, калибровку интервалов.
Что зафиксировано: метрика, данные, split и нарезка батчей, образ runner, таймауты. LLM не используется ни решателем, ни метрикой.

## Данные
См. [dataset/README.md](dataset/README.md). Пример арены — батч строк, см. [ADR-0001](../docs/adr/0001-batched-examples.md).

## Метрика
См. [metric/](metric) и раздел «Метрика» в [campaign.md](campaign/campaign.md): `MAE + 2·pinball(0.1) + 2·pinball(0.9)` в шкале `log1p` против каждого из записанных ответов, среднее по строкам. Направление: minimize. Невалидная строка: штраф 40.

## Кампания
См. [campaign/campaign.md](campaign/campaign.md): лимит 40 решений, K = 5 (с baseline), N = 5.

## Стартовый кандидат
[ways/baseline](ways/baseline): глобальные квантили 0.1 / 0.5 / 0.9 длины ответа по train, одинаковые для всех строк (медиана по train — baseline из ТЗ).
