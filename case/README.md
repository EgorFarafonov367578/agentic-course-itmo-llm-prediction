# Кейс AR-09: прогноз длины ответа LLM

Кейс оформлен по `cases/template` арены. В арену переносится только train; public и private остаются у оператора вне репозитория. Рабочая копия для запуска находится в `arena-main/cases/ar09`.

## Задача

- Вход: батч строк `{"rows": [{"id", "prompt", "model", "input_tokens"}, ...]}` — запрос, имя модели (одна из 13 open-source моделей CASTILLO) и длина запроса в её токенах.
- Ответ: `{"<id>": {"pred", "lo", "hi"}, ...}` — точечный прогноз числа выходных токенов и интервал 10–90 % для каждой строки.
- Разрешённые материалы: train (`case/dataset/data/castillo.train.jsonl`) целиком, включая `meta`; любые библиотеки и предобученные модели. Public и private недоступны.

Подробные условия и формулы — в [`campaign/campaign.md`](campaign/campaign.md).

## Разрешённые изменения

Что исследователь может менять: всё решение, без ограничений на метод, библиотеки и модели. Что зафиксировано: метрика, данные, split, нарезка батчей и таймауты. LLM не используется ни решателем, ни метрикой. Предсказание строки зависит только от её собственного входа: соседние строки батча использовать нельзя.

## Данные

См. [`dataset/README.md`](dataset/README.md). Пример арены — батч строк, обоснование — в [`docs/adr/0001-batched-examples.md`](../docs/adr/0001-batched-examples.md). Склейка повторных `sample_id` — в [`docs/adr/0002-merge-repeated-pairs.md`](../docs/adr/0002-merge-repeated-pairs.md).

Кратко: train / public / private — 83 813 / 27 905 / 27 906 строк, 175 / 60 / 59 батчей. Разделение по семействам похожих запросов, пересечений между split нет. Public и private не коммитятся.

## Метрика

Пакет: [`metric/`](metric). Формула — `MAE(pred) + 2·pinball(0.1) + 2·pinball(0.9)` в шкале `log1p` против каждого записанного ответа, среднее по строкам. Направление — minimize. Невалидная строка — штраф `40`. Пакет состоит из `metric.json`, `score.py`, `aggregate.py` и `README.md`; агрегация считает среднее по строкам, а не по батчам.

## Кампания

См. [`campaign/campaign.md`](campaign/campaign.md): лимит **40** решений, `K = 5` финалистов включая baseline, `N = 5`. Public и private оцениваются по батчам; на private уходят ровно 5 кандидатов.

## Стартовый кандидат

[`ways/baseline`](ways/baseline): глобальные квантили 0.1 / 0.5 / 0.9 длины ответа по train, одинаковые для всех строк. `fit.py` даёт `lo=59`, `pred=367`, `hi=779`; `solve.py` отдаёт валидный ответ по протоколу немодельного runner. Baseline ещё не зарегистрирован в журнале и займёт одно место после `propose`.
