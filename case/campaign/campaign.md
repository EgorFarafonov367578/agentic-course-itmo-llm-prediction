- Release ID: `ar09-c1-v1`
- Версия метрики: `ar09-quantile-v1` (заморожена до поиска, правила ниже)
- Версии данных: split `castillo-sanitized-family-split-v1`, батчи `castillo-batched-v1` (`case/dataset/batches.json`); пример арены — батч строк, см. [ADR-0001](../../docs/adr/0001-batched-examples.md). Размеры: train 174 батча (83 952 строки), public 61 (27 943), private 61 (27 948).

- Таймауты: `ARENA_RUNNER_TIMEOUT=120` с на батч (это и есть ограничение на время предсказания из реестра темы: ~240 мс на строку, включая загрузку модели); таймаут метрики 30 с на батч. Общей длительности кампании таймауты не задают.

## Задача и ответ

Вход батча: `{"rows": [{"id", "prompt", "model", "input_tokens"}, ...]}`. `meta` (источник, категория, семейство) решателю не передаётся.

Ответ: JSON-объект, по ключу на каждую строку батча — `{"<id>": {"pred": p, "lo": a, "hi": b}, ...}`, числа в токенах. `pred` — точечный прогноз, `[lo, hi]` — интервал 10 %–90 %. Предсказание строки зависит только от её собственного входа.

Прогноз времени ожидания из реестра темы не делаем: в CASTILLO нет замеров латентности, а собирать свои ответы ресурсов нет (см. `case/dataset/README.md`).

## Метрика

Всё в шкале `log1p(токенов)`; `y_1..y_k` — 5–10 записанных длин ответов пары «запрос × модель».

- `ρ_q(u) = max(q·u, (q−1)·u)` — pinball loss квантиля `q`.
- Ошибка строки: `score = 2 · mean_i [ρ_0.5(y_i − pred) + ρ_0.1(y_i − lo) + ρ_0.9(y_i − hi)]`.
  Поскольку `2·ρ_0.5(u) = |u|`, это `MAE(pred) + 2·pinball(lo, 0.1) + 2·pinball(hi, 0.9)`: MAE по каждому из 10 ответов плюс штраф за интервал. Оптимум — истинные квантили 0.1 / 0.5 / 0.9 распределения длины.
- Итог: среднее по всем строкам раздела (метрика на батч отдаёт в `statistics` сумму и число строк, `aggregation` делит одно на другое). Направление: **minimize**.
- Дополнительно в `statistics`, без влияния на score: MAE, покрытие интервала (доля `y_i` в `[lo, hi]`), средняя ширина интервала.

Невалидность:
- строка без ответа, лишний ключ, нечисловое или нефинитное значение, значение вне `[0, 1e5]`, нарушение `lo ≤ pred ≤ hi` → штраф строки `40` (больше любой валидной ошибки: при `lo ≤ pred ≤ hi` она не превышает `3 · max|log1p(прогноз) − log1p(y)| ≤ 3 · log1p(1e5) ≈ 34.5`);
- ответ не парсится как JSON-объект → штраф `40` для всех строк батча;
- сбой решателя (ненулевой exit, таймаут) — сбой проверки по правилам арены, а не score.

Ориентиры на public: медиана по train (baseline ТЗ) — MAE 0.730, оракул (медиана 10 ответов той же пары) — MAE 0.153.

## Разрешённые изменения

Меняется всё внутри пакета кандидата: признаки запроса, статистики по train, модель, обученные на train веса (файлы пакета), калибровка интервалов, код `solve.py`.

Зафиксировано: метрика, данные, split и нарезка батчей, харнес, образ runner и его зависимости, таймауты. Кандидат не получает сеть, не читает public/private и не использует соседние строки батча.

Образ runner: `ar09-runner` на базе `python:3.12-slim` с закреплёнными `numpy`, `scikit-learn`, `lightgbm` (точные версии фиксирует подготовка). **Открытый пункт для подготовки:** разрешать ли готовую модель эмбеддингов в `/assets` (для kNN по похожим запросам, упомянутого в реестре) или ограничиться признаками без предобученных моделей (TF-IDF, хэширование). Решить до заморозки.

## Лимит предложенных решений: 40

Почему столько: замер кандидата почти бесплатный (61 батч public — минуты на CPU, LLM в оценке нет), поэтому реальная цена — токены исследователей. 40 решений хватает на несколько независимых направлений (табличная регрессия по признакам, kNN по похожим запросам, квантильные модели, калибровка интервалов) по 6–10 шагов в каждом и на выход кривой на плато, с запасом по времени на перегрузку моделей курса.

## Финализация

- Финалистов на private (K): **5**, включая baseline.
- Итоговых решений (N ≤ K): **5** — оператор видит private-оценку каждого финалиста, в том числе baseline (нужно для сравнения B-6.6).
- Правило выбора 4 финалистов кроме baseline: прошедшие ревью кандидаты; лучшие по public с учётом шума (различимы разницы от ~0.015), из разных направлений, без признаков переобучения (разрыв train-CV / public), с проверкой независимости строк батча.
