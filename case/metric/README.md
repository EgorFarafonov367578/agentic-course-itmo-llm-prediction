# Метрика ar09-quantile-v1

Программная метрика без LLM, `kind: command`, направление **minimize**. Условия задаёт [`case/campaign/campaign.md`](../campaign/campaign.md), здесь — исполнимые правила и их уточнения. Пакет одинаков на train, public и private; зависимостей кроме стандартной библиотеки Python нет.

## Пример и ответ

Пример арены — батч строк ([ADR-0001](../../docs/adr/0001-batched-examples.md)). `input` — JSON-строка `{"rows": [{"id", "prompt", "model", "input_tokens"}, ...]}`, `reference` — `{"output_tokens": {"<id>": [длины], ...}}`, в строке от 5 до 30 записанных длин ([ADR-0002](../../docs/adr/0002-merge-repeated-pairs.md)). Ответ — JSON-объект `{"<id>": {"pred": p, "lo": a, "hi": b}, ...}` по ключу на каждую строку, числа в токенах.

## Оценка строки

Всё в шкале `log1p(токенов)`, `ρ_q(u) = max(q·u, (q−1)·u)`. Для строки с длинами `y_1..y_k`:

```text
loss = 2 · mean_i [ρ_0.5(y_i − pred) + ρ_0.1(y_i − lo) + ρ_0.9(y_i − hi)]
     = MAE(pred) + 2·pinball_0.1(lo) + 2·pinball_0.9(hi)
```

Среднее берётся по ответам строки, поэтому строка весит одинаково при любом `k`: склеенный повтор с 20 или 30 длинами не получает двойного веса.

## Невалидность

Строка получает штраф **40**, если:

- для неё нет ключа в ответе;
- её значение не объект или поля объекта не равны ровно `{pred, lo, hi}`: лишнее, недостающее или повторённое поле;
- значение не число (строка, `null`, `true`/`false`) или нефинитно (`NaN`, `Infinity`, переполнение вроде `1e400` или целого из сотен и тысяч цифр: целые литералы читаются как float);
- значение вне `[0, 1e5]`;
- нарушено `lo ≤ pred ≤ hi`.

Все строки батча получают штраф 40, если ответ не разбирается как JSON-объект (пустая строка, массив, число, мусор), повторяет id или содержит id, которого нет в батче. При `lo ≤ pred ≤ hi` и значениях в `[0, 1e5]` валидная ошибка не больше `3·log1p(1e5) ≈ 34.5`, поэтому штраф всегда хуже любого валидного ответа.

Ошибка во входе или эталоне (повтор id во входе, расхождение id входа и эталона, пустой эталон, длина вне `[0, 1e5]`, неразбираемый JSON) — сбой метрики: exit 1, без score. Верхняя граница эталона нужна, чтобы штраф оставался хуже любого валидного ответа; в данных длины не превышают 15 000. Сбой решателя — сбой проверки по правилам арены, его метрика не оценивает.

## Статистика и итог

`score.py` возвращает только `{"statistics": {...}}`:

| Поле | Смысл |
| --- | --- |
| `rows` | строк в батче |
| `loss_sum` | сумма ошибок строк, включая штрафы |
| `valid_rows`, `invalid_rows` | валидные и штрафные строки |
| `mae_sum` | сумма MAE валидных строк |
| `coverage_sum` | сумма долей `y_i ∈ [lo, hi]` по валидным строкам |
| `width_sum` | сумма `log1p(hi) − log1p(lo)` по валидным строкам |
| `batch_invalid` | ответ целиком не соответствует батчу |
| `invalid_reasons` | счётчик причин: `batch`, `missing`, `fields`, `type`, `range`, `order` |

`aggregate.py` возвращает `score = Σ loss_sum / Σ rows` по всему набору — среднее по строкам, а не среднее средних по батчам разного размера. Пустой, неполный или противоречивый набор (нет `statistics`, повтор `example_id`, `rows < 1`, нечисловой или отрицательный `loss_sum`) — сбой агрегации.

## Проверки

```bash
python3 -m pytest case/tests/test_metric.py
```

Тесты проверяют точные значения на синтетических батчах, оптимальность истинных квантилей, строки с 14/20/30 длинами, отсутствие роста веса строки при повторе ответов, все виды невалидных строк и батчей, повторённые ключи, огромные целые, нефинитные числа и агрегацию по строкам.
